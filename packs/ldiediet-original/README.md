# LDieDiet Original

The original 17 L’DieDiet groups, six nutrition scales, formulas, and exclusions, extracted from the mod JAR. Original JSON rules are preserved. This is an archive of original settings, not a universal vanilla pack: rewards reference third-party effects/conditions and achievements in the `offseason` namespace.

Put the ZIP in `<world>/datapacks`, then run `/reload`. Do not combine it with All of Food or All of Food Vanilla: IDs overlap. Nutrition requires food profiles from configuration, Diet import, or your own datapack. Choose All of Food for a ready-made food catalog, or All of Food Vanilla for vanilla-only play.

Minecraft 1.20.1 / Forge / L’DieDiet 2.0.0. Datapack format 15. [MIT license](LICENSE).
